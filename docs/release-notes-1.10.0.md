# Splity 1.10.0 更新說明

1.9.8 之後使用者看得到的改動只有花費分類（`c58b635`..`4491245`）。
字元上限 whatsNew 4000。`scripts/asc_submit.py` 只寫 zh-Hant。

## zh-Hant

<!-- field: ZH_WHATSNEW limit:4000 -->
```
這一版新增了什麼：

・花費分類：記帳時依品項名稱自動選分類，例如打「加油」會選交通、打「晚餐」會選餐飲。猜錯也可以自己改，改過的不會再被蓋掉。
・帳本的花費列表會顯示分類圖示，共享帳本的每個人都看得到。
・新增「分類統計」：用圓餅圖看這趟旅程錢都花在哪裡，各分類的金額與比例一目了然。

覺得分類不合用？在分類統計畫面點「分類不合用？告訴我們」就能寫信給我們。
```
